# kubeflow-pipelines-e2e

demand forecasting pipeline on kubeflow. gke + gcs + vertex model registry.

wip. more to come.

## what this is

end to end retail demand forecast for a big-box style store network. features from BigQuery,
xgboost + prophet baseline, model registered in vertex ai for downstream scoring.

## quick start

```
make setup
make compile
make submit
```
